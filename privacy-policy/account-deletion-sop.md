# StarGuardians 계정·제3자 데이터 삭제 운영 절차

최종 갱신: 2026-07-20

이 문서는 DodoSoft 운영자가 StarGuardians 계정 삭제 요청을 빠뜨리지 않고 처리하기 위한 체크리스트다. 비밀번호, 인증 토큰, 신분증 원본, 전체 구매 영수증, 결제수단 정보는 요청하거나 이 문서·처리 기록에 남기지 않는다.

## 1. 접수와 최소 확인

1. 무작위 요청 번호, 접수 시각, 요청 경로(앱/이메일)를 기록한다.
2. 외부 요청은 별도 제한이 없는 한 다음 전체 범위로 접수한다.
   - 회사가 관리하는 계정·게임·소셜 데이터
   - 식별 가능한 Firebase Analytics·Google Cloud 운영 데이터
   - Unity IAP 5.4 IAP Insights·처리자 데이터 삭제 전달
3. 플랫폼, 닉네임 또는 친구 코드, 로그인 제공자, 최근 접속 시각으로 계정 소유를 최소 확인한다.
4. 구매 데이터 확인이 필요한 경우에만 주문·거래 ID 등 최소 식별자를 추가로 받는다. 전체 영수증이나 결제수단은 받지 않는다.
5. 요청에 불필요한 비밀정보가 들어오면 즉시 삭제하거나 가린 뒤 처리 사실만 기록한다.

## 2. 회사 관리 데이터

1. 앱 내 삭제 또는 검증된 서버 삭제 절차를 실행한다.
2. 다음 완료 여부를 확인한다.
   - Firebase Authentication 실사용 계정과 Google/Apple 연결 제거
   - 세이브, 지갑, 인벤토리, 덱, 진행도, 우편, 보상, 쿠폰, 동의 상태 삭제
   - 프로필, 친구·요청·차단 관계, 클랜 가입·역할·가입 요청, 카드 교환 관계 정리
   - PvP·클랜전 직접 계정 연결 정리
   - 퇴역 경매의 잔여 매물 취소와 생존 이용자 에스크로 반환
   - 결제·AdMob SSV·퇴역 경매 감사 원장의 원문 uid 제거 및 도메인 분리 일방향 표식 교체
   - 삭제 차단 표식 생성 후 지연 토큰·광고 콜백으로 데이터가 재생성되지 않음
3. 법정 또는 보안상 보존하는 항목은 일반 데이터와 분리하고 접근을 제한한다.

## 3. 제3자 삭제 라우팅

### Firebase Analytics 23.2.0·Google Cloud

1. 요청자가 제공한 앱 인스턴스·광고 식별자 또는 내부에서 합법적으로 확인 가능한 최소 식별자로 삭제 가능한 범위를 확인한다.
2. 제공자 콘솔·API·지원 절차에서 식별 가능한 Analytics 및 운영 로그 데이터를 삭제한다.
3. 앱 인스턴스 식별자가 Firebase uid와 직접 연결되지 않아 식별할 수 없는 데이터, 프로젝트 보존 설정, 계속되는 법적·보안 보존 근거를 처리 결과에 구분해 기록한다.
4. Google이 독립적으로 관리하는 AdMob 광고 데이터는 Google 개인정보 요청과 광고 ID 관리 절차를 이용자에게 안내한다. 회사의 SSV 원장은 2절에 따라 가명화한다.

### Unity IAP 5.4 IAP Insights

1. Unity가 DodoSoft를 대신해 처리하는 데이터는 운영자가 `unity-iap-contact@unity3d.com`으로 수동 삭제를 지시한다.
2. 요청에는 앱 이름·패키지, 플랫폼, 요청 범위와 필요한 최소 거래·Unity 설치 식별자만 포함한다.
3. 전체 영수증, 결제수단, Firebase 인증 토큰, 비밀번호는 Unity에 보내지 않는다.
4. 발송일, Unity 제공자 티켓, 회신일, 완료일과 삭제 불가 항목·근거를 요청 번호 아래 기록한다.
5. Unity가 독립적으로 관리하는 데이터는 이용자가 같은 주소로 직접 요청할 수 있음을 안내한다.
6. Unity가 안내하는 IAP 서비스 로그의 일반 보존기간은 90일이다. 다른 거래·Insights 데이터는 Unity의 역할·처리 목적과 최신 정책을 확인한다.

## 4. 완료와 처리기록

1. 통상 7영업일 안에 결과를 안내한다. 복잡한 거래·법적 보존 검토는 최대 30일까지 걸릴 수 있으며 지연 사유를 알린다.
2. 결과에는 회사 관리 데이터, Firebase/Google, Unity IAP별 상태와 완료일, 남은 항목·근거, 이용자가 해야 할 제공자 후속 절차를 적는다.
3. 일반 요청의 이메일·첨부·본인 확인 자료는 결과 안내 후 지체 없이 삭제한다. 소비자 불만·분쟁 기록이면 관련 법령에 따라 최대 3년간 별도 보관할 수 있다.
4. 처리기록에는 요청 번호, 시각, 시스템별 상태, 제공자 티켓과 법적 근거만 남긴다. 원문 uid·토큰·전체 영수증은 남기지 않는다.

## 5. 출시 전 재확인

- 개인정보처리방침 한국어·영어 페이지와 계정 삭제 페이지의 항목이 동일한지 확인한다.
- Firebase Analytics, AdMob/UMP, Unity IAP, Firebase/Auth/Firestore/Functions/App Check, Play Integrity 버전·설정 변경 여부를 확인한다.
- Google Analytics 광고 링크·데이터 공유 설정과 AdMob mediation/광고 기술 제공자 목록을 확인한다.
- 제공자 정책이나 삭제 주소가 바뀌면 이 절차와 공개 페이지를 함께 갱신한다.
- 외부 공개 전 `python3 privacy-policy/verify-policy-consistency.py`를 실행해 전수 PASS인지 확인한다.
